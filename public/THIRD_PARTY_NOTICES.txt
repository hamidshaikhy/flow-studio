# اعتبار و مجوزهای دیگر

- React / React DOM: Meta and contributors، MIT. https://github.com/facebook/react
- React Flow (`@xyflow/react`): xyflow، MIT. مکانیک بوم به این کتابخانه متکی است. https://github.com/xyflow/xyflow
- Zustand: contributors، MIT. https://github.com/pmndrs/zustand
- Zod: Colin McDonnell and contributors، MIT. https://github.com/colinhacks/zod
- idb: Jake Archibald، ISC. https://github.com/jakearchibald/idb
- Lucide: Lucide contributors، ISC؛ بخشی از آیکون‌های مشتق از Feather تحت MIT. https://github.com/lucide-icons/lucide
- Vazirmatn: The Vazirmatn Project Authors، SIL Open Font License 1.1. مجوز کامل قلم در `docs/licenses/Vazirmatn-OFL.txt` قرار دارد. https://github.com/rastikerdar/vazirmatn
- Vite، Tailwind CSS، Vitest، Testing Library: مجوزهای خود بسته‌ها در نصب npm حفظ می‌شوند؛ فهرست دقیق نسخه‌ها در lockfile است.
- Playwright: Microsoft، Apache-2.0؛ ابزار توسعه و بررسی، بخشی از برنامهٔ runtime نیست.
- TypeScript: Microsoft، Apache-2.0؛ ابزار build و بررسی.

قلم داخل bundle قرار دارد و از CDN هنگام استفاده دریافت نمی‌شود. فایل‌های مجوز runtime در `docs/licenses/` همراه پروژه‌اند. مجوز پیشنهادی MIT برای کد اصلی، مجوز بسته‌ها یا دارایی‌های بالا را تغییر نمی‌دهد و هنوز نیازمند انتخاب مالک است.

API آموزشی زنده: JSONPlaceholder، https://jsonplaceholder.typicode.com/. دادهٔ آزمایشی فارسی این پروژه جدا و محلی است.
